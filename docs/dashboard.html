Honest scope caveat 500 ps is short relative to real desorption/diffusion timescales. This result supports "curcumin does not spontaneously desorb on a sub-nanosecond timescale under these conditions" — it is not proof of long-term (µs–ms, biologically relevant) stability, which would need a literature-scale 50+ ns run beyond this project's compute budget. It also builds on an explicitly-documented "parameterize by chemical analogy" force field (no AmberTools/acpype access in this environment) — see the GitHub repo's README for the full methodology and the two real geometry bugs found and fixed along the way.
Project 2 of a two-part computational nanomedicine study. Full methodology, scripts, topology files, and raw analysis data: github.com/sareer555/curcumin-GO-MD-GROMACS. Project 1 (DFT binding energies): github.com/sareer555/curcumin-doxorubicin-GO-DFT.
